# 🌐 Web Development Project

A beginner-friendly web development project built with **HTML5 and CSS3**.

This project contains multiple webpages created to practice webpage structure, styling, layouts, images, and responsive web design concepts.

The project is intentionally simple and framework-free. It does not require a backend server, database, or external library.

## 🔗 Live Demo

The project can be opened directly in a web browser.

**GitHub Repository:**
https://github.com/FARIYA233

---

## ✨ Features

### 🏠 Multiple Webpages

The project contains several HTML pages, including:

* Main webpage
* Additional HTML pages
* Different webpage layouts
* Navigation between pages

### 🎨 CSS Styling

The project uses CSS to create:

* Page layouts
* Typography
* Spacing
* Images
* Buttons
* Sections
* Visual styling

### 🖼️ Images

The project also includes image resources used to improve the visual appearance of the webpages.

### 📱 Responsive Layout

The webpages are designed to work on different screen sizes, including:

* Desktop
* Laptop
* Tablet
* Mobile devices

## 🛠️ Technology Stack

| Technology | Purpose                       |

| CSS3       | Styling, layout, and design   |
